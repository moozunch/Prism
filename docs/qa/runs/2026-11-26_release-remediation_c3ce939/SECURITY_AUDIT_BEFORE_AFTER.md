## Composer

`composer audit --locked --format=json` pada mesin Codex mencapai batas proxy HTTP 403 sebelum mendapatkan hasil. Alternatif independen memeriksa semua 174 versi terkunci (121 runtime dan 53 dev) terhadap 354 entri versi terkait dalam GitHub Advisory Database Packagist yang sudah ditinjau. Snapshot `fb93ce73c92f553d66455bf917999fc8a9a64863`, tanggal commit 25 November 2026. Pemindaian awal menemukan satu advisory LOW Laravel. Laravel diperbarui dari 12.69.2 ke 12.71.0. Pemindaian atas lock tersebut selesai dengan nol temuan pada snapshot. Hasil dibatasi pada tanggal dan sumber tersebut.
